># FriendsCommunity
# Sistema de Chat Colaborativo
## Documentación actualizada

Proyecto desarrollado con Node.js y WebSocket para comunicación en tiempo real.

## Tecnologías usadas

- Node.js
- WebSocket
- HTML
- CSS
- JavaScript

## Funcionalidades

- Chat en tiempo real
- Mensajes instantáneos
- Usuarios automáticos
- Historial de mensajes
## Instalación y ejecución

1. Node.js instalado
2. Git instalado
3. Clonar el repositorio 
 - https://github.com/abad-villca-Gutierrez/FriendsComunity.git
4. Entrar a la carpeta 
 - cd FriendsComunity
5. Instalar dependencias 
 - npm install
6. Ejecutar el servidor
 - node server.js o npm start
7. Abrir en el navegador
 - http://localhost:3000
8. Probar desde diferentes redes 
 - npx hostc 3000
9. Compartir el url que genera
